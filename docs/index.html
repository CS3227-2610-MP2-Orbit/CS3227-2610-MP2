01 / ORGANIZE

Club Organizer

Turn a club's idea into an event students can join.

  • Create clubs and draft events
  • Request venues and publish events
  • View registrations and assign volunteers
  • Send event announcements
Organizer guide ↗
02 / COORDINATE

Venue Administrator

Keep campus rooms and booking requests in order.

  • Create and manage venues
  • Review, approve or reject requests
  • Review overlapping booking conflicts
  • Manage user accounts and roles
Administrator guide ↗
03 / TAKE PART

Attendee

Find something worth showing up for.

  • Search events and filter by club or date
  • Register, cancel and view your bookings
  • Read updates in your notification inbox
  • Check in and revisit attendance history
Attendee guide ↗

Check-in uses a normal button during the event. Notifications are delivered inside the app, not by email. See current limitations.
